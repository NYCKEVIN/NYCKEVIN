## 👨‍💻 About Me

- 📱 Desarrollador **mobile** enfocado en **Flutter & Dart**, construyendo apps multiplataforma (Android, iOS, Web y Desktop).
- 🧱 Me gusta el código ordenado: **arquitectura limpia**, gestión de estado con **BLoC** e inyección de dependencias con **get_it**.
